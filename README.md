# X

Proyecto personal.

Sitio estático (HTML, CSS y JavaScript, sin compilación) con [Supabase](https://supabase.com) para cuentas y datos. Se publica en [Vercel](https://vercel.com).

## Puesta en marcha

1. En Supabase → SQL Editor, ejecutar `supabase.sql`.
2. Poner la URL del proyecto y la clave *publishable* en `config.js`.
3. En Vercel, importar el repositorio y publicar.
